# ONLINE_FS_THEBRIDGE_MSIMARRO — Proyectos

**Full Stack Developer + IA · The Bridge · Promoción marzo 2026**

Repositorio de proyectos desarrollados a lo largo del bootcamp **Full Stack Developer + IA** en [The Bridge](https://www.thebridge.tech/). Cada proyecto vive en su propia carpeta dentro de la rama `main` y se publica mediante **GitHub Pages**.

---

## Demo en vivo

[msimgit.github.io/ONLINE_FS_THEBRIDGE_MSIMARRO_PROJECTS](https://msimgit.github.io/ONLINE_FS_THEBRIDGE_MSIMARRO_PROJECTS/)

La URL siempre mostrará el proyecto activo en ese momento. La raíz del repositorio contiene un `index.html` que redirige automáticamente a la carpeta del proyecto actual. A medida que avance el curso, esa redirección apuntará al nuevo proyecto sin alterar los anteriores.

```html
<!-- index.html raíz — redirección automática al proyecto activo -->
<meta http-equiv="refresh" content="0; url=./projectbreak1/index.html" />
```
