# Project Break 1 — Dashboard

Primer proyecto del curso **Full Stack Developer** en The Bridge.

Un dashboard personal construido con HTML, CSS y JavaScript puro, sin frameworks ni librerías externas. El objetivo es consolidar los fundamentos del frontend desarrollando cuatro herramientas funcionales accesibles desde una página principal.

---

## Páginas

| Archivo | Descripción |
|---------|-------------|
| `index.html` | Página principal con las cuatro tarjetas de acceso |
| `pages/reloj.html` | Reloj digital 24h con fecha |
| `pages/meteo.html` | Estación meteorológica |
| `pages/pass.html` | Generador de contraseñas seguras |
| `pages/links.html` | Listado de links con imágenes de fondo aleatorias |

---

## Tecnologías

- HTML5
- CSS3 — Grid, Flexbox, custom properties
- JavaScript vanilla
